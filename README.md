# Vocab Builder

Vocab Builder is a simple vocabulary learning application that helps users search for English words, understand their meanings, save useful words, and practice them through a quiz.

## Features

- **Word Search:** Search for English words using the Dictionary API.
- **Word Details:** View meanings, phonetics, parts of speech, and examples.
- **Saved Words:** Save words to your personal vocabulary list.
- **Search Saved Words:** Find words from your saved list.
- **Delete Words:** Remove words from your saved list.
- **Quiz:** Practice vocabulary using saved words.
- **Progress Tracking:** Track quiz attempts and correct answers.
- **Local Storage:** Save vocabulary and quiz progress in the browser.

## Technologies Used

- HTML
- JavaScript
- Tailwind CSS
- Dictionary API
- Browser Local Storage

## API Used

[Free Dictionary API](https://dictionaryapi.dev/)

This API provides word meanings, phonetics, parts of speech, and examples.

## Getting Started

1. Clone this repository:

   bash
   git clone https://github.com/beherakiran/vocab_Builder.git
   

2. Open the project folder.

3. Open `index.html` in your browser.

No additional installation or API key is required.

## How to Use

1. Enter an English word in the search box.
2. View its meaning and other details.
3. Save words that you want to learn.
4. Visit the My Words section to manage saved vocabulary.
5. Start the quiz to test your knowledge.
6. Check your progress in the My Progress section.
